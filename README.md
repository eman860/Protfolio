# Imman — Portfolio

This repository contains the source code for Imman's personal developer portfolio.

## Project name
Imman | Aspiring Software Developer — Portfolio

## Description
A modern, responsive portfolio showcasing projects, skills, experience, education, research, and contact information. Includes lightweight animations and interactive effects for a premium developer presentation.

## Technologies
- HTML
- CSS
- JavaScript

## Features
- Hero section with typewriter effect and animated background
- Smooth scroll-triggered reveal animations (IntersectionObserver)
- Animated skill progress bars with moving gradients
- Project cards with hover tilt and premium hover effects
- Experience timeline, achievements, problem-solving counter
- Contact form (client-side validation)
- Back-to-top button and subtle cursor follower (desktop)

## How to run locally
1. Clone the repository:

```bash
git clone <your-repo-url>
cd <repo-folder>
```

2. Serve files locally (one of the options):

Using Python 3:
```bash
python3 -m http.server 5500
# then open http://localhost:5500/index.html
```

Using VS Code Live Server extension (recommended):
- Open the folder in VS Code and click "Go Live".

## Deployment
You can deploy the site to platforms like Vercel, Netlify, or GitHub Pages by pointing the platform to this repository.
